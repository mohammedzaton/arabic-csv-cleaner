# منظّف CSV العربي

أداة بايثون مجانية ومفتوحة المصدر لتنظيف ملفات CSV على جهازك، دون إرسال بيانات
لأي موقع. مناسبة لملفات الأصناف والكميات المستخرجة من الأنظمة أو إكسل.

## الوظائف

- تحويل ٠١٢٣ و۰۱۲۳ إلى 0123 مع الاحتفاظ بالأصفار في بداية الأكواد.
- حذف المسافات من أطراف الخلايا وعناوين الأعمدة وتوحيد Unicode بصيغة NFC.
- اكتشاف الصفوف المتكررة بعد التنظيف وحذفها اختياريًا.
- رفض أسماء الأعمدة الفارغة أو المتكررة والصفوف بعدد أعمدة خاطئ.
- إخراج ملف UTF-8 مع BOM وتقرير JSON، وعدم استبدال أي ملف موجود.

لا تترجم الأداة أسماء الأعمدة، ولا تحوّل النصوص لأرقام، ولا تغيّر التواريخ أو
الحروف العربية أو الفواصل العشرية. تدعم CSV فقط وليس ملفات XLSX مباشرة.

## التشغيل

ثبّت Python 3.10 أو أحدث، وفك الضغط وافتح الطرفية داخل مجلد المشروع:

```sh
python -m arabic_csv_cleaner examples/input.csv cleaned.csv --deduplicate
```

على Windows يمكنك استخدام `py` بدل `python` إذا لزم.
الملف التجريبي يحتوي على ثلاثة صفوف، سيبقى اثنان بعد إزالة التكرار.
لتنظيف ملفك استبدل مسار المثال بمساره، واستخدم اسمًا جديدًا للناتج.

للملفات القديمة استخدم `--encoding cp1256`، وللفاصل المنقوط استخدم
`--delimiter ";"`. يوجد وضع اختياري `--safe-excel` يضيف علامة اقتباس مفردة
للخلايا التي تبدأ بعلامات الصيغ، بما فيها الأعداد السالبة وعناوين الأعمدة.
قد تختلف طريقة تعامل برامج الجداول مع الملفات؛ راجع البيانات المستوردة.

لحفظ التقرير أضف `> report.json` إلى نهاية الأمر. الأكواد تحتفظ بأصفارها داخل
CSV، لكن عليك استيراد عمود الكود كنص في إكسل حتى لا يحذفها إكسل تلقائيًا.
