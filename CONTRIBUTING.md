# Contributing

Bug reports, focused fixes, Arabic documentation and real-world edge cases are welcome.
Use synthetic data in issues: never upload customer records, credentials or bank exports.

1. Fork and create a branch.
2. Add a regression test for behavior changes.
3. Run `python -m unittest discover -s tests -v`.
4. Explain the problem and expected result in your pull request.

No generated contribution counts, purchased engagement or duplicate pull requests.
